# 路线记录功能

## 当前四张 Test Street 测试场景

四张测试场景默认只导出 PNG；移动操作说明和路线记录状态面板均隐藏。移动、复位、暂停及录制按键仍然可用。

- G / Xbox X / Quest 左手 X：第一次开始，第二次停止并保存。Quest 按键适配已保留，仍需头显实机验证。
- 记录时先点击 Game 画面，让游戏接收键盘输入。
- 开始与保存路径显示在 Unity Console，不叠加在游戏画面。
- 默认保存到当前用户 Documents/DM2350_Results/参与者编号/本次记录编号。
- PNG 文件名包含参与者编号、组别、场景名和时间，连续记录不会覆盖。
- 四张图的组别为 G1（白天）、G2（11 盏路灯，只有路灯照明）、G3（24 盏路灯及窗户/商店照明）、Preview_Unlit（无人工照明测试）。

## PNG-only 模式

路线点先保存在内存里；正常停止时创建目录并导出一张俯视路线 PNG。不创建 CSV、JSON、.partial 或其他旁侧数据文件。请先按录制键停止并保存，再退出 Play 或切换场景；中断、退出、崩溃前的内存路线不会自动生成图片。

在 Hierarchy 中选择 Street Night Studio（白天为 Street Daylight Studio），可在 Route Recorder 组件里调整匿名参与者编号、组别、采样间隔、保存目录、地图范围和分辨率。默认参与者编号仍为 P001；开始正式记录前应更换。

图片底图由真正的正上方正交摄像机拍摄，保留场景材质和停止时的灯光状态。黄色为路线，绿色为起点，红色为终点；左上箭头指向世界坐标 +Z。修改探索范围后应检查 Map Bounds。复位或跳变会另起路线段，避免连出穿墙的直线。

## 可选原始数据导出

如之后需要原始坐标和时间，可在 Route Recorder 中打开 Export Raw Data。该选项默认在现有旧组件上保留原行为，但在这四张测试场景中明确关闭。记录开始时锁定本次输出模式，中途改变选项仅影响下一次记录。

开启时保留原来的 trajectory.csv、session.json 和 route.png 导出，也会在录制过程中定期刷新 .partial 和元数据。CSV 记录位置、视点、方向、灯光和控制模式等；头部方向不是眼动追踪。关闭该选项时这些信息仅在内存中用于记录，不会写入原始数据文件。

如果 PNG 保存失败，Console 会显示失败原因，不会把失败误报为成功；当前组件的内存路线点暂时保留。再次开始记录会清空上一条内存路线。

## 设备与保存位置

电脑编辑器或 Windows 程序把图片保存到运行它们的电脑。Quest Link 也使用电脑端保存；Quest 独立运行保存到应用数据目录，不会自动传到电脑。记录功能不会主动更改移动模式；F1/F2/F3/F4 仍负责切换原有模式。

48 张 Group 场景本次没有修改。现有数据文件不会被删除。仅本地改动，没有提交或推送 Git。
