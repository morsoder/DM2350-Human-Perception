# 夜间光照改进版 — 月光、连续配光、独立间接光烘焙

## 三个场景

- Test Street Night with no Light：0/24 路灯、0/2 摊位，没有人工照明，按暗夜参考图单独保留更弱的月光与天空底光。
- Test Street Night with Low Light：11/24 路灯、0/2 摊位，所有窗户、商店和招牌照明均关闭。
- Test Street Night：24/24 路灯、2/2 摊位，以及原来的较多亮窗。

少灯档在上一版基础上额外关闭 Street Lamp 07，灯体发光同步关闭。本次进一步关闭少灯档所有窗户、商店和招牌照明，并单独重新烘焙；较亮档保持原来的窗户和商店照明。

## 本次调整

少灯和较亮场景共用月光强度 0.08、颜色 (0.83,0.88,1)、阴影强度 0.65。天空、水平和地面的环境光分别为 (0.06375,0.07225,0.0935)、(0.02975,0.03485,0.04675)、(0.0153,0.01785,0.02465)。天空盒保持原来的夜空，固定曝光保持 0，对比度从 10 调整为 0。

每盏路灯仍为强度 90、原颜色和原位置；范围从 20 扩到 34、外角从 105° 扩到 140°、内角 65°，阴影强度 0.82。这些 Unity 强度值不是实际测得的照度。

本目录中的独立 Forward+ 渲染配置用于三张夜晚场景，支持大块路面接收更多重叠灯光。白天、原始素材和全局项目渲染配置没有改动。

## 反弹光

每张地图各自烘焙一套间接光，位于 Bake 0/1/2。主要静态表面使用烘焙光照贴图，动态物体使用 264 个烘焙光照探针。月光、路灯和摊位采用 Mixed/Baked Indirect：直接光实时计算，反弹光预先保存。较亮档的暖色窗户和招牌发光参与烘焙；少灯档这些发光全部关闭并重新烘焙。移动/动画物件、部分透明和不适合烘焙的网格不作为静态接收表面。

本次为效果审阅版，烘焙分辨率 2 texels/m、间接采样 128、3 次反弹。部分缺少第二套 UV 的模型使用本目录下的网格副本补齐，未修改原模型导入设置、物体位置和碰撞体。

三张地图拥有各自独立的灯光数据。更改灯光数量、位置、亮度或亮窗名单后，需要为对应场景重新烘焙；仅切换控制器枚举无法同步改变已保存的反弹光。较亮场景的烘焙结果不能给无灯场景使用。

## 使用

退出 Play 后重新打开相应场景，再进入 Play 查看。相同视角对比图保存在此次工作输出中。需要用 Quest 3 实机确认头显内的暗部可见度和性能；此次只完成桌面验证。

已保留修改前本地备份，没有提交或推送 Git。

## 无灯场景：按暗夜照片进一步压暗

根据用户确认的参考图，仅无灯场景降低光照，使建筑以轮廓为主、砖纹和窗框更难辨认，路面仍保留微弱走向。月光强度 0.025，颜色 (0.78,0.84,1)，阴影强度 0.75。环境天空光 (0.012,0.014,0.020)，水平光 (0.004,0.005,0.008)，地面光 (0.002,0.0025,0.004)，环境反射 0.06。独立天空材质 Unlit Moonlight Sky 的曝光为 0.04。相机曝光、共享后期配置均保持不变。

月光方向调整为 Euler (35,180,0)，沿街道照来，减少对近处两侧建筑立面的正面照明，保留路面微弱高光。

已单独重新烘焙无灯场景；少灯档仍为 11 盏，较亮档仍为 24 盏，两张已照明场景没有改动。本视觉草稿中的无灯场景使用更弱的自然底光，已不与另外两档共用完全相同的自然光基准；正式实验参数需据最终研究设计统一确认。
