# 三档夜晚灯光 — 第一版

三个场景使用相同的夜空、微弱环境光、月光、曝光、后期处理、单灯亮度与颜色、街道布局和移动设置。无灯指没有人工照明，而不是纯黑画面。

| 场景 | 路灯 | 已有住宅窗户发光组 | 营业摊位 |
| --- | --- | --- | --- |
| Test Street Night with no Light | 0 / 24 | 0 / 76 | 0 / 2 |
| Test Street Night with Low Light | 12 / 24 | 28 / 76 | 1 / 2 |
| Test Street Night | 24 / 24 | 76 / 76 | 2 / 2 |

窗户的数字是受控材质槽/窗帘渲染组数量，不等同于独立物理窗户数；原素材的一个组可能覆盖多个窗格。较亮档的 76 组是原场景已有的亮窗布置，不是点亮整张地图的所有窗户。

每处摊位包含橱窗和招牌两个发光组，以及原有的两个照明组件；三档分别开启 0、2、4 个摊位照明组件。没有制作真实室内。

少灯档固定开启路灯 01、03、05、07、09、11、13、15、17、19、21、23。窗户采用固定路径散列选择，运行时不会随机改变；少灯档开启的灯和窗户都包含在较亮档中。现有路灯强度 90、月光强度 0.018 保持一致，不将 Unity 数值解释为现场测得的照度。

夜间版本使用本目录的独立材质拷贝，以保存各自发光状态并避免影响白天/备份场景；未纳入实验控制的其他发光材质在三档均保持不发光。没有新增闪烁。反射探针使用实时启动更新，避免旧的灯光反射残留。

使用：退出 Play 后打开对应场景，再进入 Play。灯光控制组件在 Street Night Studio 上。每张场景保存了自己的亮灯名单与材质；选择 F/G 枚举只改变条件标签及模式，不能代替打开对应场景，也不会自动把这一场景的名单替换为另一场景的名单。原 A–E 模式保持原有逻辑；本次 F/G 名称也会写入路线数据的 lightingCondition 字段。

修改亮灯名单时，灯体发光与 Light 组件必须同步。后续应在头显中检查实际亮度与可见度，再确定正式实验版本。
